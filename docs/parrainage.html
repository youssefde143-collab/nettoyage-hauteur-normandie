FAQ · Parrainage

Questions sur le parrainage

Qui bénéficie de la réduction ?

La personne recommandée, sur sa première intervention. Elle indique le code de parrainage dans sa demande de devis, et la réduction de 20 % apparaît sur la proposition qui lui est remise.

Que reçoit la personne qui recommande ?

Le parrainage ne donne pas lieu à un avantage supplémentaire pour la personne qui recommande. L'offre est entièrement destinée au filleul.

Comment obtenir mon code de parrainage ?

Les codes sont nominatifs et attribués par CleanVitreService. Si vous êtes déjà client, demandez le vôtre par téléphone ou par e-mail : il vous est communiqué directement.

Où saisir le code ?

Dans le formulaire de devis, à la première étape, au champ « Vous avez un code parrainage ? ». Vous pouvez aussi l'indiquer de vive voix si vous appelez.

Le code est-il vérifié ?

Oui. Chaque code est rattaché à un client parrain et peut être activé ou désactivé. Un code inconnu, désactivé ou déjà utilisé hors des règles prévues n'ouvre pas droit à la réduction.

La réduction s'applique-t-elle à plusieurs interventions ?

Non. Elle porte sur la première intervention du filleul. Les modalités particulières — durée de validité, cumul éventuel avec une autre offre — sont précisées par CleanVitreService lors de l'établissement du devis.
